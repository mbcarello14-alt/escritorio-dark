# Storyboard: Sócrates, Platão ou Aristóteles? Como o ENEM cobra

Mapa único (3 ramos): centro "Filosofia antiga: Atenas"; ramos Sócrates (perguntas), Platão (Ideias), Aristóteles (eudaimonia), cada um com 3 filhos. `revelar` cresce de 0 a 3.

## 1. Gancho: o nome de graça (6 cenas)
imagem (Escola de Atenas) -> cartão "Aristóteles" -> cartão "eudaimonia" -> comparação nome x conceito -> mapa (0) -> ilustração de engajamento

## 2. Atenas, 399 a.C. (8 cenas)
doodle tribunal -> imagem (Morte de Sócrates) -> cartão "não escreveu nada" -> lista três gerações -> mapa (0) -> comparação em cima/embaixo -> cartão "traduzir" -> mapa (1)

## 3. Primeiro tronco: Sócrates (7 cenas)
doodle praça -> doodle ironia -> lista método -> doodle parteira -> mapa (1) -> lista ética -> citação vida examinada

## 4. Os vizinhos: ENEM 2017 (7 cenas)
comparação vizinhos -> mapa (1) -> cartão ENEM 2017 -> lista alternativas -> comparação eliminação -> cartão letra B -> imagem busto de Platão

## 5. Segundo tronco: Platão (8 cenas)
mapa (2) -> doodle escritor -> cartão fonte -> doodle dois mundos -> comparação mundos -> imagem caverna -> doodle saída da caverna -> cartão caverna = conhecimento

## 6. A cidade justa: ENEM 2025 (7 cenas)
mapa (2) -> cartão ENEM 2025 -> lista cidade ideal -> cartão letra D -> cartão letra E -> ilustração de engajamento (isca) -> doodle aluno cético

## 7. Terceiro tronco: Aristóteles (6 cenas)
mapa (3) -> cartão eudaimonia -> lista corrente -> cartão fim da corrente -> doodle razão -> lista do galho

## 8. Mediania e política (9 cenas)
comparação virtude -> doodle gangorra -> cartão mediania -> doodle sal -> cartão desconfie -> cartão animal político -> lista ética/política -> comparação politeia x democracia -> cartão aviso

## 9. Você completa o mapa (7 cenas)
doodle aluno -> mapa (1) -> mapa (2) -> mapa (3) -> cartão rodapé -> lista 3 passos -> cartão passo 1

## 10. Questão final: ENEM 2020 (11 cenas)
cartão ENEM 2020 -> imagem busto de Aristóteles -> cartão comando -> mapa (3) -> comparação bem/cidade -> lista A e B -> lista C, D, E -> comparação eliminadas -> cartão D armadilha -> cartão letra A -> cartão eudaimonia

## 11. Fechamento (6 cenas)
cartão -> mapa (3) -> cartão pegadinha -> comparação D x E -> ilustração de engajamento -> doodle próximo mapa

Notas: imagens de arquivo em domínio público (Escola de Atenas, David, gravura da caverna, bustos romanos). Doodles de ilustração levam `busca_reserva`. Sem `sintetico_realista`.
